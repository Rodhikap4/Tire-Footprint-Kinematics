def low_pass_filter(data, cutoff, fs, order=4):
    nyquist = 0.5 * fs
    normal_cutoff = cutoff / nyquist
    b, a = butter(order, normal_cutoff, btype='low', analog=False)
    return filtfilt(b, a, data)

final Calculations

From Detected 397 complete contact patches we Calculate Duration (Delta t) & Filter out noise. A real contact patch at 10km/h should be significant. If it's too short (< 0.05s), it's likely just a bump. Used "continue" to Skip fake ones. Finaly used a core equation in physics, Angle = Speed*Time.

In [189]:
results = []

for t_start_idx, t_end_idx in zip(starts, ends):
    duration_sec = (t_end_idx - t_start_idx) * dt
    if duration_sec < 0.05:
        continue
    omega_deg_s = df['gx'].iloc[t_start_idx:t_end_idx].mean()
    alpha_deg = abs(omega_deg_s * duration_sec)
    
results.append(alpha_deg)
